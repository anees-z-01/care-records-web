# care-notes-app

The Next.js package for the care notes web client. Setup, Docker commands, the API contract and design notes are in the [repository README](../../README.md).

Quick start with Node 22 and the API on `http://localhost:8000`:

```sh
npm ci
cp .env.example .env.local
npm run dev
```

`npm test`, `npm run lint`, `npm run type-check` and `npm run build` are the checks.
